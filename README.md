# Dreamward (Somnium) — 2D-игра в жанре психологической пошаговой RPG

**Платформа:** WPF (.NET 10, C# 12, MVVM, Entity Framework Core SQLite, System.Text.Json)

---

## 1. Описание и назначение
Интерактивная 2D-игра в жанре психологической пошаговой RPG, включающая:
- Исследование двумерного пространства сновидений на базе `Canvas` (`W, A, S, D` или стрелки);
- Бесшовное зацикливание координат при достижении границ экрана в стартовой локации **White Nook**;
- Плавный переход между комнатами с анимацией затемнения (`Fade-In / Fade-Out` через свойство `Opacity`);
- Взаимодействие с сюжетными объектами, сундуками и точками сохранения по клавише `E` или `Enter`;
- Инвентарь расходных предметов трёх категорий: **+HP**, **+SP**, **-Уровень Страха**;
- Пошаговую боевую систему (`ATTACK`, `ACT / SKILL`, `ITEM`, `MERCY / RUN`) с динамическим влиянием шкалы **«Уровень Страха» (0–100%)**:
  - `0–30%` — Стабильное состояние;
  - `31–70%` — Тревога (штраф к точности базовых атак);
  - `71–100%` — Паника (рост входящего урона и стоимости SP, открытие отчаянной способности «Прорыв Паники»);
- Локальную базу данных **SQLite** (`Microsoft.EntityFrameworkCore.Sqlite`) + экспорт и импорт резервных копий в **JSON** (`System.Text.Json`).

## 2. Сборка и запуск (.NET 10)
```bash
dotnet restore
dotnet build
dotnet run
```

## 3. Публикация в единый исполняемый файл (п. 4.6 ТЗ)
```bash
dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true
```
Локальная база данных `dreamward.db` создаётся и инициализируется автоматически при первом запуске.
